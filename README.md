# 프로젝트 달마루

한국 설화를 바탕으로 한 마인크래프트 RPG 프로젝트입니다. 가제는 **달마루**, 개발용 식별자는 `MCRPG`입니다.

- [설계 탐색](docs/README.md)
- [문서 관리 기준](docs/DOCUMENT_CONTROL.md)
- [요구사항 정의서](docs/REQUIREMENTS.md)
- [현재 상태](PROGRESS.md)
- [검증 결과](TEST_RESULT.md)
- [Work 프로젝트 지침](docs/WORK_PROJECT_INSTRUCTIONS.md)

`docs/`는 프로젝트의 공식 설계·요구사항·사양 기준입니다. 구현 코드는 `server-project/`에 있으며, 실제 동작과 완료 여부는 코드 및 `TEST_RESULT.md`의 재현 가능한 증거로 판단합니다.

문서 간 책임·우선순위·변경 절차는 [문서 관리 기준](docs/DOCUMENT_CONTROL.md)을 따릅니다. `docs/archive/`는 과거 기록이므로 현재 기준이나 구현 완료 증거로 사용하지 않습니다.

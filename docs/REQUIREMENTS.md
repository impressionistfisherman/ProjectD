# 달마루 요구사항 정의서

이 문서는 달마루의 요구사항을 한곳에서 찾고 구현·시험 증거와 연결하기 위한 상위 목록이다. 게임의 세부 규칙은 담당 설계 문서가 기준이며, 이 문서에 같은 내용을 반복하지 않는다.

구현 요청, 커밋, 시험 결과에는 해당 요구사항 ID를 기록한다. 구현 여부를 이 문서에 따로 표시하지 않으며, 실제 결과는 `PROGRESS.md`와 `TEST_RESULT.md`에서 확인한다.

## 7. 추적 규칙

- 규칙을 바꾸면 담당 상세 설계를 먼저 갱신하고, 이 문서의 연결을 유지한다.
- 첫 시험 운영 밖 항목은 삭제하지 않고 정식 확장으로 남긴다.
- 구현 전제는 [세부 규칙과 예외 처리](RULES_AND_OPERATIONS.md), 시험 콘텐츠 수치는 [시험 콘텐츠 명세](PILOT_CONTENT_SPEC.md), 데이터·통신 계약은 [데이터 계약](DATA_CONTRACTS.md)을 따른다.
- 콘텐츠 ID와 시험 ID는 화면에 보이는 이름이 바뀌어도 바꾸지 않는다.

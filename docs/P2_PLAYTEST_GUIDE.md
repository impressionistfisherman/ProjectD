# P2 사람 플레이 가이드

새 캐릭터 하나로 1레벨에서 20레벨까지 간다. 경험치와 장비는 명령으로 넣지 않는다. `/dalmaru xp`와 `/dalmaru-equipment`는 쓰지 않는다.

이 문서는 `Dalmaru-mdf-p2-oscar`의 P2 통합 화면 기준이다. 서버와 클라이언트는 같은 통합 JAR과 통신 버전 32로 맞춘다. 사람 플레이 완료를 뜻하지 않으며 배포·교체는 별도 승인 후 진행한다.

키는 코드 기본값이다. `K` 캐릭터, `J` 프로필, `U` 퀘스트, `O` 안내, `E` 장비, `F6` 공략, 왼쪽 `Alt` 회피, `` ` `` 전투 모드.

임시: 마을 좌표와 주민 외형, 대사 `이 문안은 초안입니다.`, 유료 초기화 비용 레벨×10전.

## 1. 시작 물품은 한 번

조작: 접속하면 캐릭터 화면이 열린다. 없으면 `K`. 이름을 넣고 `생성하기`. 슬롯을 눌러 선택한다.

기대: 수련 장비 1개, 회복 물품 4개, 20전. `E`에서 장비를 본다. 재접속해도 수량은 그대로다. `삭제`를 누르면 `확인: 삭제`가 되고, 다시 눌러야 삭제된다. 다른 슬롯을 고르면 확인이 풀린다. 7일 안에 `복구`하면 물품이 늘지 않는다. 슬롯에는 `삭제 대기`가 붙는다.

실패 시: 화면 상태 줄. 삭제·복구가 안 나가면 아직 고른 캐릭터가 없는 것이다. 다른 캐릭터를 고른 뒤에만 나간다. 서버 로그 `Character life request failed`.

## 2. 필수 이야기만으로 1~20

조작: `U` → `1~20 이야기`. 화면 위에 제목, 필수 전투 경험치, 빠진 조건이 나온다. `NPC 상호작용`, 조건이 차면 `개인 보고 · 완료 보상`, `새로고침`.

순서: 태평의 새벽, 청하의 물길, 깨어난 들판, 꺼진 봉화의 소문, 네 갈래의 길, 전직 시험, 새 무기의 길, 봉인 훼손 조사, 폐봉수대 초행, 봉수패의 기록, 불길 되살리기.

기대: 좀비 의뢰만으로 20이 되지 않는다. 각 구간 보고 뒤에 다음 제목과 빠진 조건이 보인다. 20에 닿는다.

실패 시: 화면의 빠진 조건 첫 줄. NPC 이름 옆 좌표는 3번의 마을 안내와 같다. 좌표는 임시라 건물은 없다.

## 3. 직업 마을, 전직, 기술, 직업 장비

조작: 직업 마을 좌표 안으로 걸어 들어간다. 철위성 전사 `400, 64, 0`, 청림촌 궁수 `0, 64, 400`, 운학촌 법사 `-400, 64, 0`, 흑조포 도적 `0, 64, -400`. 태평현은 `0, 64, 0`. 반경 32. `J` → `마을 안내`에서 이름·좌표·초안 대사를 본다. `J` → `전직 선택`에서 전사·궁수·법사·도적. 화면 문구는 `10레벨 · 직업 마을 방문`, `해당 직업 시험 · 이야기 완료`. 전직 시험 구간에서는 플레이어와 처치 대상이 같은 선택 직업 마을 안에 있어야 필수 전투 200 XP가 쌓인다. 전직 선택 뒤 `U` → `1~20 이야기`에서 해당 직업 NPC에게 개인 보고해야 직업 장비를 받는다. 그다음 `J` → `기술 습득`.

기대: 10레벨 무기 2개와 방어구 4개가 한 번 생긴다. 공통 기술을 배운다. 다시 전직하거나 장비가 한 벌 더 생기지 않는다.

실패 시: 채팅 `전직 조건을 충족하지 못했습니다. 10레벨·직업 마을 방문·전직 시험·이야기 완료가 필요합니다.` 좌표 밖이면 방문이 안 남는다.

## 4. 조사의 실패, 함께하는 단계, 개인 보고

조작: 임시 현장은 `800, 64, 800`, 반경 24다. 그 칸의 장치 `800, 64, 800` 반경 4에 서 있거나, 구역 안에서 전투 중일 때만 현장이 된다. `J` → `조사` → `현장` → `확정`. 서버가 증거 조각 `quest.seal_fragment`를 기록하면 `증거` → `확정`. 임시 보고 위치 `820, 64, 800` 반경 4에서 `최종 보고` → `확정`. 버튼의 확정은 요청일 뿐이다.

기대: 조건 없이 세 단계를 확정해도 단계는 안 올라가고 보상은 0이다. 조건을 채운 최종 보고 한 번에 40전, 회복 4개, 15레벨 장비 교체, 경험치 600. 같은 보고를 다시 해도 더 주지 않는다. 한 사람이 서버 조건을 채워 현장을 확정하면 나중에 연 사람도 현장만 확정이다. 증거와 보고는 각자다. 확정된 단계에서 실패를 누르면 거절되고, 그 단계는 남는다. 이후 `U`의 봉인 훼손 조사 개인 보고는 이야기 진행만 처리하며 경험치 600과 물품을 다시 주지 않는다.

실패 시: 상태 줄 `이 조사 단계는 진행할 수 없습니다.` 구역 밖이거나 전투·장치가 없으면, 조각이 없으면, 보고 위치 밖이면 거절된다. 직업이 없으면 보고는 롤백된다. 서버 로그 `Quest stage request failed`.

## 5. 15레벨 장비와 수련 준비

조작: 4의 최종 보고로 15레벨 장비를 받는다. 이야기 폐봉수대 초행까지 간 뒤 `F6` → `초행 입장`. 준비되면 `준비 완료`. 초행을 끝낸 뒤 이야기 불길 되살리기로 20을 맞추고 `F6` → `수련 입장`.

기대: 명령 없이 15레벨 장비로 바뀌고, 강화 단계는 유지된다. 수련은 초행 완료와 20레벨 뒤에 열린다. 주 3회를 넘기면 막힌다.

실패 시: 채팅 `초행은 15레벨, 수련은 20레벨부터 입장할 수 있습니다.` `초행을 완료한 뒤 수련에 입장할 수 있습니다.` `이번 주 완료 횟수 3회를 모두 사용했습니다.`

## 6. 역참 귀환

조작: 마을 좌표 안에 서 있으면 그 역참이 해금된다. `O` → `역참 귀환`. `목록 새로고침`, 목적지 버튼을 눌러 고르고 `선택 역참으로 귀환`. 8초 안에 `귀환 취소`. 명령은 `/dalmaru-waypoint`, `/dalmaru-waypoint return <마을 id>`, `/dalmaru-waypoint cancel`.

기대: 가 본 마을만 목록에 있다. 채팅 `귀환 준비 8초: 이동·공격·피격 시 취소됩니다.` 걷거나 공격하거나 맞으면 취소된다. 끝나면 `역참 귀환을 완료했습니다. 재사용 대기시간은 15분입니다.` 공략 중에는 거절된다.

실패 시: 버튼 `해금된 역참 없음`. 채팅의 취소 문구. 좌표는 임시라 지도에 마을이 없어도 그 칸에 서면 해금이다.

## 7. 유료 초기화, 삭제 유예, 20 상한

조작: `J`의 초기화 버튼. 처음은 `무료 초기화`, 이후는 `초기화 N전`. 한 번 더 누르면 `확인: …` 상태에서 나간다. 삭제는 1번과 같다. 20이 되면 프로필 위에 `시험 상한 도달, 초과 경험치 보관 중`.

기대: 첫 초기화는 전을 쓰지 않는다. 다음은 임시 비용인 레벨×10전을 걷고, 직접 넣은 힘·재주·도력·체력·정신만 미배분점으로 돌아온다. 장비, 직업, 클리어 기록, 쓴 무료 초기화는 남는다. 전이 부족하면 능력치도 돈도 그대로다. 7일 안 복구는 그 기록을 유지한다. 레벨은 20에서 멈추고 넘친 경험치는 그 칸에 남는다. 정식 전환 때 어떻게 보여줄지는 아직 없다.

실패 시: 버튼이 `확인`으로 바뀌기 전에 요청이 나갔는지 본다. 서버 로그 `Character life request failed`. 20 문구가 없으면 레벨이 20 미만이거나 오스카 프로필 화면이 아닌 것이다.

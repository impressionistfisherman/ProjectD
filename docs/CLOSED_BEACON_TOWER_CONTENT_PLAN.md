# 폐봉수대 콘텐츠 제작 계획

> 문서 ID: CTP-001 · 분류: 콘텐츠 제작 계획 · 상태: 구현 전 확정 · 대상 콘텐츠: `pilot-2` · 적용 기준: 2026-09-28

## 1. 범위와 기준

폐봉수대는 15레벨 초행, 20레벨 수련으로 제공하는 10~15분 일반 던전이다. 기존 전투 수치·난이도 배율·최초/반복 보상은 [PILOT_CONTENT_SPEC](PILOT_CONTENT_SPEC.md)의 폐봉수대 절을 기준으로 유지한다.

이 문서는 해당 명세에 없던 보스 연출, 공간 구조, 제작 방식을 확정한다. 구현은 이 문서의 최소 플레이 루프만 대상으로 하며 멀티플레이, 재접속, 보상 원자성 검증은 루프 완성 뒤에 수행한다.

## 2. 보스 2종

| 보스 | 외형 | 체력·방어·자세 | 공격 패턴 | 처치 결과 |
|---|---|---|---|---|
| 철문수장 | 철 투구·방패를 든 좀비. 이름은 `철문수장` | 10,800 / 물리 80·마법 55 / 자세 650 | ① 철문 강타: 전방 근접 110. ② 방패 밀치기: 전방 부채꼴 130, 짧은 밀침. ③ 지면 강타: 재사용 대기 후 원형 150. 체력 50%부터 지면 강타만 1회 연속 사용 | 다음 문을 열고 화로 구역을 활성화한다. 직접 보상은 없다. |
| 원혼봉수장 | 사슬·푸른 불꽃 효과를 두른 좀비. 이름은 `원혼봉수장` | 14,400 / 물리·마법 80 / 자세 900 | ① 봉화 창: 대상 방향 원거리 130. ② 혼파: 전방 파동 120. ③ 원혼 화염: 바닥 경고 뒤 범위 180. 100~70%는 ①, 70~35%는 ①+②, 35~0%는 ①+②+③을 사용한다. | 처치 시 공략 성공을 확정하고 보상 구역 상자를 연다. |

- 모든 보스는 속박 면역이며 기존 직업 스킬의 보스 둔화 규칙을 따른다.
- 공격명은 전투 경고와 로그에 그대로 사용한다. 회피 불가능한 즉사 공격, 추가 소환 몬스터, 별도 광폭화는 이번 범위에서 만들지 않는다.

## 3. 던전 맵과 이동 흐름

맵은 되돌아갈 필요 없는 단방향 구조로 만든다. 각 구역 사이에는 닫힌 철문 또는 자연스러운 낙차를 두어 다음 단계가 시작되기 전 진입하지 못하게 한다.

```text
[입구·준비] ── 철문 ── [철문수장 방] ── 해제문 ── [화로 구역]
                                                     │ 화로 정화 성공
                                                     v
                                               [원혼봉수장 방] ── 보상문 ── [보상 구역]
```

| 구역 | 최소 구조 | 완료 조건·다음 전환 |
|---|---|---|
| 입구·준비 | 시작 표지, 귀환 불가 안내, 1개 통로 | 입장 후 철문수장 방으로 이동한다. |
| 철문수장 방 | 15×15 이상 평면 투기장, 중앙 보스, 네 모서리 엄폐 기둥 | 철문수장 처치 시 출구 철문을 연다. |
| 화로 구역 | 일렬 주 통로 양쪽에 화로 3개, 각 화로 앞 상호작용 공간 | 시작 인원에 따라 1/2/3개를 4초 안에 동시 정화한다. 방치하면 기존 명세대로 경고 후 전원 마법 피해 150을 준다. 성공 시 최종 보스 방을 연다. |
| 원혼봉수장 방 | 17×17 이상 평면 투기장, 중앙 보스, 가장자리 4개 기둥 | 원혼봉수장 처치 시 보상문을 연다. |
| 보상 구역 | 파티원별 상자 위치와 퇴장 통로 | 서버가 성공 보상을 확정한 뒤에만 각자의 상자를 연다. |

## 4. 제작 방식 결정

첫 구현은 바닐라 좀비와 블록 구조물을 사용한다. 보스의 구분은 장비, 이름, 입자·사운드, 보스바로 해결하며 리소스팩, Blockbench 전용 모델, 전용 텍스처는 만들지 않는다.

이 선택은 현재 서버의 좀비 보스 생성 경로를 그대로 사용하고, 모든 플레이어가 별도 클라이언트 자산 없이 플레이하게 한다. 전용 모델은 아래 조건이 확인될 때만 별도 작업으로 추가한다.

- 바닐라 외형 때문에 두 보스의 식별 또는 공격 예고가 실제 플레이에서 혼동될 때
- 최소 플레이 루프의 전투 시간과 완료율이 목표를 충족한 뒤에도 콘텐츠 품질 개선이 필요할 때

## 5. 구현 순서와 완료 조건

1. 위 구조의 고정 맵과 구역 전환을 만든다.
2. 철문수장 전투와 처치 문 개방을 연결한다.
3. 화로 동시 정화와 원혼봉수장 전투를 연결한다.
4. 최종 처치 후 서버 확정 보상 상자를 연다.
5. 1인 초행으로 입장부터 상자 개방까지 수동 완주한다.

5번이 통과하기 전에는 신규 멀티플레이 기능, 재접속 처리, 보상 중복 검증 범위를 넓히지 않는다. 기존 서버 로직은 폐기하지 않고 이 루프에 연결해 검증한다.

# Codex 최소 인계
작업 크기와 검증은 [협업 규칙](DEVELOPMENT_WORKFLOW.md)을 따른다. 현재 구현 상태와 Active Spec은 [PROGRESS](../PROGRESS.md), 필요한 설계만 [Router](README.md)에서 선택한다.

다음 형식에 이번 변경만 작성한다. 이미 전달된 지침은 복사하지 않는다.

> 대상 저장소/전달본: 경로와 리비전 또는 전달 시각
> 목표와 범위: 이번 변경
> 요구 동작과 제약: 기존 동작에서 달라지는 점
> 완료 조건: 관찰 가능한 결과
> 요구사항 ID: [요구사항 정의서](REQUIREMENTS.md)의 관련 ID
> 참조: 관련 파일·절 또는 Active Spec

작은 작업은 목표·변경·완료 조건만으로 충분하다. 구현 세부사항은 기존 코드에 맞춰 결정한다.
과거 인수 요약은 archive에 보존한다. 현재 규칙의 근거로 사용하지 않는다.

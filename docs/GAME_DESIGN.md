# 달마루 게임 설계

## 1. 방향

달마루는 한국 설화 속 존재와 지역의 이야기를 탐험하는 마인크래프트 RPG 서버의 가제이다. 플레이어는 중앙마을에서 시작해 직업을 선택하고, 퀘스트와 공략을 통해 자신만의 캐릭터를 성장시킨다.

- Java Edition 전용 소규모 모드팩. 한국 설화풍 창작 세계, 탐험·퀘스트 중심 RPG.
- 중앙마을 시작 → 10레벨에 직업 마을에서 전직. 직업은 캐릭터별 유지.
- 한 계정에서 여러 캐릭터를 생성하고 공용 창고를 이용할 수 있다. 시험 운영과 첫 정식 운영은 캐릭터 슬롯 4칸을 제공하며, 이후 확장은 재화 공급을 확인한 뒤 정한다.
- 전사·궁수·법사·도적. 30레벨에 2개 분기 중 선택, 50레벨 후속 승급, 60레벨 마스터 승급.
- 최대 레벨 60. 승급은 레벨만으로 자동 완료되지 않고 직업별 퀘스트 필요.
- 이름 하나 안에서는 순우리말 또는 한자어 조합 통일. 실제 역사와 창작 구분.
- 직업별 마을은 모두 방문 가능. 전직·직업 이야기만 해당 직업 조건 적용.

## 2. 성장

- 힘·재주·도력·체력·정신 직접 배분. 추천은 안내만 하며 자동 투자 없음.
- 1레벨에는 추가 배분점 없이 시작, 2~60레벨마다 5점 = 295점.
- 능력치 초기화는 캐릭터별 최초 1회 무료, 이후 레벨 비례 재화 비용.
- 장비에서도 다섯 능력치 획득. 초기화는 직접 투자분만 반환.
- 경로당 액티브 10개(일반 9+궁극기 1), 패시브·특성 7개 = 17개.
- 동시 장착은 일반 4개+궁극기 1개. 기본 공격·회피·무기 보조 조작은 슬롯 별도.
- 스킬 장착 변경은 마을·공략 시작 전 준비 공간. 공략이 시작되면 장착 목록을 서버가 고정하며, 사망·관전·재접속 뒤에도 변경할 수 없다.
- 스킬 최대 81점으로 전체 마스터 가능한 안. 세부는 직업 문서 참조.
- 산적·해적 분기 선택 시 힘·재주를 다시 배분할 수 있는 무료 재배분을 제공하는 방안을 권장한다. 일반 무료 초기화 횟수와는 별도로 취급한다.

## 3. 전투 모드

| 지역 | 규칙 |
|---|---|
| 마을 | 전투·비전투 수동 자유 전환. 전투 모드 자체가 PvP 허용을 뜻하지 않음 |
| 필드 | 수동 전투 진입, 비전투 중 유효 공격·피격 시 자동 진입 |
| 필드 복귀 | 마지막 유효 공격·피격·지원 후 10초 초과 시 비전투 자동 복귀, 카운트다운 표시 |
| 던전·레이드 | 전투 모드 고정 |

숫자키 1~5는 전투 중 장착 스킬, 비전투 중 퀵바 사용. 유효 공격·지원·지속 피해의 판정과 준비 공간 예외는 [세부 규칙과 예외 처리](RULES_AND_OPERATIONS.md)를 따른다.

## 4. 던전·레이드

| 항목 | 일반 던전 | 레이드 |
|---|---|---|
| 입장 인원 | 1~4 | 1~8 |
| 인원 구간 | 1 / 2 / 3~4 | 1 / 2 / 3~4 / 5~8 |
| 적용 기준 | 1 / 2 / 4인 | 1 / 2 / 4 / 8인 |
| 클리어 한도 | 콘텐츠·난이도별 주 3회 | 콘텐츠·난이도별 주 1회 |

- 횟수는 캐릭터별. 같은 난이도의 솔로·파티는 공유. 서로 다른 난이도는 독립.
- 도전 무제한, 실패 시 횟수 소모 없음. 한도 도달 시 해당 난이도 입장 불가.
- 초행 → 수련 → 시련 → 극한 순차 개방.
- 하위 난이도 클리어 기록은 캐릭터·콘텐츠별 영구 유지.
- 난이도별 최소 레벨. 파티 전원 레벨·개방·남은 횟수 충족.
- 공략 시작 명단·난이도·보정 구간 고정. 중도 이탈로 난이도 하향 불가.
- 3인으로 4인 기믹, 5인으로 8인 기믹 수행 가능해야 함.
- 초기화: 일반 던전과 레이드 모두 한국 시간 매주 목요일 06:00.
- 공략 시작 시 시작 주기의 횟수를 예약하고, 성공 시만 사용 확정한다. 실패·포기·시간 만료는 예약을 해제한다. 일반 던전 45분, 레이드는 90분 상한과 초기화 경계 처리는 [세부 규칙과 예외 처리](RULES_AND_OPERATIONS.md)를 따른다.

## 5. 사망·부활

| 난이도 | 추가 부활 횟수 |
|---|---:|
| 초행 | 5 |
| 수련 | 3 |
| 시련 | 2 |
| 극한 | 1 |

- 사망 후 5초부터 클릭 부활 가능, 15초에 자동 부활. 생명력35%·기력25%로 사망 위치에서 부활한다.
- 실제 부활 시 1회 차감. 0이 되어도 살아 있으면 계속 전투, 이후 사망 시 부활 불가.
- 공략 중 횟수 보충 없음. 중간 보스 처치로 회복하지 않음.
- 파티 전원이 동시에 사망 상태가 되면 남은 횟수와 무관하게 전멸. 예약 부활 취소.
- 솔로는 예외: 부활 횟수가 남으면 계속 부활 가능.
- 부활 후 3초 피해 면역. 이동 시 유지, 공격·스킬 사용 시 해제. 위험 지형에서는 같은 전투 구역의 안전 바닥 또는 지정 부활 지점을 쓴다.
- 재도전은 새 공략, 개인 부활 횟수 새로 부여.
- 부활 때 유지되는 재사용 시간·고유 자원·기믹 효과, 안전 위치의 경계 규칙은 [세부 규칙과 예외 처리](RULES_AND_OPERATIONS.md)를 따른다.

## 6. 파티 운영

- 최대 8명, 직업 중복 허용. 같은 계정의 캐릭터는 한 공략에 하나.
- 직접 초대·모집 게시판, 전원 준비 후 시작. 인원·난이도 변경 시 준비 해제.
- 시작 후 신규 충원 불가. 원래 참여자의 재접속만 허용.
- 방장은 모집·가입·공략 선택·위임 가능. 보상 변경·강제 시작 불가.
- 방장 접속 종료 2분 후 접속 중인 최선임 파티원에게 위임.
- 자진 이탈은 재합류·보상 포기. 클리어 횟수는 차감 안 함.
- 포기는 접속 중 참여자 과반수 찬성. 2인은 모두 동의.
- 추방은 전투 밖 안전 구간, 대상 제외 전원 동의. 2인 진행 중 추방 불가.
- 최종 보스 시작~보상 정산 끝까지 추방 금지.
- 정상 참여 후 사망·관전도 보상 인정. 공격량만으로 자격 판단 금지.
- 접속 종료 10초 잔류 개체, 이후 5분 재접속 유예. 잔류 중 피해·사망 반영.
- 생명력·기력·부활 횟수·쿨다운 유지. 접속 종료 캐릭터는 전멸 방지 생존자로 취급하지 않음.
- 전원 접속 종료 시 최대 5분 정지하며, 원래 참가자만 재접속할 수 있다. 전멸·접속 종료·서버 장애의 처리 우선순위는 [세부 규칙과 예외 처리](RULES_AND_OPERATIONS.md)를 따른다.

## 7. 보상

- 개인 보상 + 특별 보상. 특별 보상은 솔로 직접 획득, 파티 참여자 경매.
- 최고 입찰자 낙찰. 낙찰금은 낙찰자 제외 자격자에게 균등 분배한다.
- 아무도 입찰하지 않으면 특별 보상 소멸.
- 입찰액 확보, 최고가 변경 시 이전 입찰자 금액 해제.
- 경매 수수료 없음. 나머지 전은 경매 UUID로 정한 순서에 따라 1전씩 분배, 총액을 보존한다.
- 접속 종료해도 낙찰·분배는 저장 후 보관함 지급. 경매 전 복귀 대기 최대 60초.
- 경매는 45초, 마감 10초 안의 유효 입찰은 최대 총 120초까지 연장한다. 최소 입찰가·상승폭, 단독 자격자 경매, 유찰 처리는 [세부 규칙과 예외 처리](RULES_AND_OPERATIONS.md)를 따른다.

## 9. 퀘스트·몬스터

- 본편·직업·지역·탐사·생활·의뢰·공략으로 구분. 필수 이야기의 일일 시간 제한 없음.
- 조사·추적·교섭·해원·토벌·수집·호송·의식 조합. 필수 퀘스트품은 극저확률 금지.
- 일반 선택지는 후일담·외형·관계에 영향. 필수 성장 영구 봉쇄 금지.
- 같은 단계의 현장 참여자에게 전투·장치 공유. 대화 선택·최종 보고는 캐릭터별.
- 증거·유품은 개인 지급, 일반 재료 납품은 각자. 낮은 피해량만으로 보상 박탈 금지.
- 실패 시 해당 구간만 재시작, 확정한 조사·수집 단계 유지.
- 단순 클리어 확인은 기존 기록 활용. 필수 단서 누락 시 보상 없는 조사 공간.
- 중립·우호 존재 구분. 우호 NPC 일반 공격 불가, 중립 적대화는 명시적 사건.
- 적 역할: 돌격·수비·사격·술법·지원·교란. 초반 2종, 중반 3종 조합부터 시작.

## 10. 첫 던전: 폐봉수대

- 초행 목표 10~15분. 폐쇄 성문 → 철문수장 → 봉수로 정화 → 원혼봉수장.
- 철문수장: 방패 돌진/횡단 베기/수비 태세/지면 강타. 벽에 돌진 유도 시 자세 감소.
- 봉수로: 적 정리 후 화로 조작, 피격 시 조작 중단, 완료 화로 유지. 반복 즉사 낙사 지양.
- 최종 보스: 100~70% 수비의 잔영, 70~35% 번지는 원한, 35~0% 최후의 봉화.
- 봉화참(전방 베기), 낙화탄(위치 예고), 원혼 집결(화로 접근 저지), 역화(화로 위험), 봉화 폭주(정화로 위력 감소).
- 인원 1/2/4 기준 화로 1/2/3개, 최대 동시 조작 요구 1/1/2명. 솔로 조작 중 보스는 긴 준비 동작.
- 초행은 기믹 실패 즉시 전멸 지양. 극한 완전 방치는 전멸 가능하되 명확한 경고.
- 특별 보상 기존 경매 적용. 봉수패로 지정 제작식·장비 교환. 장례/봉인 선택은 다음 본편 공통 진입.

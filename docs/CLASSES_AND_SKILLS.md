# 직업과 스킬

네 기본 직업은 30레벨에 두 계열로 나뉘며, 선택한 계열을 따라 50레벨과 60레벨에 승급한다. 각 성장 경로는 공통 기술과 전용 기술을 합해 17개로 구성된다.

표에서 ‘사용’은 직접 사용하는 일반 기술, ‘지속’은 조건에 따라 적용되는 패시브, ‘궁극’은 궁극기, ‘특성’은 마스터 승급으로 얻는 고유 능력을 뜻한다.

## 구성과 포인트

- 경로당 공통 6 + 30레벨 5 + 50레벨 4 + 60레벨 2 = 17.
- 일반 액티브 9×5점 + 일반 패시브 6×5점 + 궁극기 3점 + 특성 3점 = 81점.
- 각 단계 1점. 1단계부터 핵심 기능 사용. 5단계에 필수 이동·자원 기능을 숨기지 않음.
- 전직 6점 + 11~60레벨 50점 + 30승급 5점 + 50승급 10점 + 마스터 10점 = 81.
- 전직/승급 지연 시 레벨 포인트 누적 보관. 투자 총량 검증은 서버에서.
- 전직6/30승급31/50승급61/마스터81 누적. 초기화는 능력치와 별도 최초 무료·이후 레벨 비용.
- 직업별 공통 24개 + 분기별 11×8개 = 서로 다른 기술 정의 112개.

## 세부 설계 사항

- 1~20레벨 공통 기술의 계수·기력·쿨다운·제어는 [시험 콘텐츠 명세](PILOT_CONTENT_SPEC.md)를 따른다. 30레벨 이후 분기 기술은 해당 Phase의 콘텐츠 표에서 같은 형식으로 확정한다.
- 고유 자원의 최대치·초기치·획득 간격·감소 속도는 분기별 데이터로 정의한다. 모든 직업을 같은 최대치로 맞추지 않는다.
- 무기당 정확한 보조 키와 회피 취소 가능 프레임을 정의해야 함.
- 패시브가 동일 강화 효과를 순환 증폭하지 않도록 발동 출처 추적 필요.
- 치명타·속성·제어 가능 여부는 기술별 명시. 부활 기술은 없음.

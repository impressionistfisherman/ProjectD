# 시험 운영 계획

첫 시험 운영은 1~20레벨의 성장과 폐봉수대 공략을 중심으로 진행한다. 캐릭터 생성부터 전직, 장비 획득과 강화까지 하나의 플레이 흐름으로 연결하고, 이후 분기 승급과 레이드로 범위를 확장한다.

## 1. 시험 범위

| 포함 | 구체적 범위 |
|---|---|
| 캐릭터 | 생성·선택·전환·개인 저장, 시험 4슬롯 |
| 성장 | 레벨1~20, 직접 능력치, 10전직 |
| 직업 | 네 직업·공통6개씩, 무기 조작 비교 |
| 마을 | 태평현+직업4마을 핵심 동선 |
| 퀘스트 | 시작→전직→폐봉수대 조사 |
| 공략 | 폐봉수대 초행15/수련20, 솔로·2·3·4인 |
| 경제 | 개인 보상·특별 경매·창고·금고·귀속·직접 거래 |
| 장비 | 레벨별 성장 장비·기본 능력치·강화+1~5·실패 누적 |
| 생활 | 채광→가공→야장 기초, 다른 직업 장비는 퀘스트·상점·보상 제공 |
| 운영 | 저장·멱등·재접속·서버 장애 복구 |

정식 상한60과 전체 설계는 유지. 레이드·30분기·마스터·고단 강화·재련·시장 거래소·전체 제작은 첫 공개 시험 범위에서 제외한다. 단, 강화·재련 확률 규칙은 게임 외 단위 검증으로 전 구간 확인 가능하다.

## 2. 개발 순서

| 단계 | 산출물 | 다음 단계 진입 조건 |
|---|---|---|
| A. 버전 검증 | 버전 명세, 클라이언트+전용 서버 최소 모드 | 화면·키·패킷·전용 서버 기동, 클라이언트 코드 서버 로딩 없음 |
| B. 데이터 기반 | 계정/캐릭터/소유권/재화/연결 잠금 | 두 연결 경합·재접속·중복 요청·장애 검증 |
| C. 전투 기반 | 능력치·무기·회피·방어·24공통 기술 | 네 직업 조작·키 충돌·거리 검증 |
| D. 성장 동선 | 퀘스트·전직·마을 | 신규 캐릭터가 시작~전직을 막힘 없이 진행 |
| E. 공략 | 파티·인스턴스·데스카운트·첫 보스 | 1/2/3/4인 완주와 전멸·재접속 검증 |
| F. 보상·경제 | 클리어·경매·강화·기초 제작 | 원장·소유권·횟수의 원자성 검증 |
| G. 사용자 시험 | 실제 플레이 기록·이슈 분류 | 치명적 복제/손실/진행불가 없음, 수정 후 관련 회귀 |

개발은 최소 모드의 기동과 통신 확인부터 시작하며, 이후 캐릭터·전투·공략·경제 순으로 확장한다.
## 3. 구체적 검증 항목

### 규칙 시험
- 60레벨 포인트295, 각 성장 경로17개, 스킬 비용81점, 지급81점.
- 난이도별 클리어 독립, 솔로/파티 공유, 콘텐츠/캐릭터 간 분리.
- 3→4인, 5~7→8인. 최소 구간 인원으로 동시 기믹 수행 가능.
- 부활5초 미만 금지/5초 허용/15초 자동, 실제 부활 때만 차감.
- 파티 전원 사망은 남은 횟수와 무관 전멸, 솔로는 남으면 부활.
- 부활면역3초와 공격·스킬 해제, 이동 유지.
- 강화 실패+5%p/재련+10%p, 확률100% 상한, 성공 시 해당 누적만 초기화.
- 강화+15 기본 능력치40% 증가, 추가 속성과 파생 생명력 중복 강화 없음.

### 저장·경제 시험
- 강화 요청 중복: 차감·추첨·보정 변경 한 번, 같은 결과 반환.
- 창고 동시 이동: 한 아이템이 두 위치에 생기지 않음.
- 재료 묶음 분할/병합: 총수량 유지, 음수 금지.
- 경매 입찰 경합: 최고 입찰·보유금 예약 일치, 패자 예약 해제.
- 낙찰 순간 장애: 물품1개·총낙찰금 분배 보존·재정산 중복 없음.
- 클리어 확정 전후 장애: 미완료 예약 해제, 완료 횟수와 보상 함께 유지.
- 초기화 경계: 시작 주기의 예약 확정, 새 주기 횟수 오염 없음.
- 삭제·복구·캐릭터 변경: 계정창고와 횟수·무료혜택 중복 없음.

### 수동·멀티플레이 시험
- 1~20레벨 네 직업 솔로 성장, 3인4인보정 기믹, 지원/관전 보상 자격.
- 비전투↔전투 키 전환, 메뉴 입력 중 스킬 오발 방지.
- 피격 예고와 정확 방어를 50/100/200ms 왕복 지연 환경에서 비교; 합격 허용치는 체감 평가 후 확정.
- 낮은 클라이언트 프레임에서 공격 횟수·피해량이 달라지지 않음.
- 갈고리·축지·회피로 경계·봉인·다른 인스턴스 진입 불가.
- 안전 지역 NPC 공격 불가. 일반 상자·투척·호퍼·모루로 귀속 우회 불가.
- 가방 가득 찬 상태 보상, 접속 종료자의 경매 낙찰·분배.

시험에서는 환경과 재현 절차, 기대한 결과와 실제 결과를 함께 기록한다.

## 4. 추가로 정할 사항

다음 항목은 해당 기능을 만들기 전에 세부 동작과 수치를 정한다.

| 번호 | 항목 | 설계 방향 | 관련 단계 |
|---|---|---|---|
| D01 | 준비 공간의 스킬 변경과 던전 전투고정 | 준비/공략 상태 분리, 준비에서는 장착 허용 | 공략 상태 구현 전 |
| D02 | 지원 행동·지속 피해의 교전 시간 | 실제 공격·유효 지원은 갱신, 기력 자연회복은 갱신하지 않음 | 전투 모드 구현 전 |
| D03 | 부활 생명력·기력·위험 지형 | 비율과 안전 위치 범위를 정의, 순간이동 기믹 우회 금지 | 부활 구현 전 |
| D04 | 전원 사망·전원 접속종료·서버 장애 우선순위 | 마지막 접속 생존자 사망은 전멸, 생존 상태 전원 이탈은 정지 검토, 서버 장애는 별도 | 공략 상태 구현 전 |
| D05 | 초기화 직전 시작·장기 정지 공략 | 시작 주기 귀속 유지, 공략 만료 시간 설정 | 횟수 예약 구현 전 |
| D06 | 실시간 경매 단독 자격자·마감·최소가 | 시작 인원과 최종 경매 자격 수 구분, 자동 무료 전환 금지 | 경매 구현 전 |
| D07 | 캐릭터 슬롯·이름·분기 변경 | 시험4칸, 정식 슬롯 및 30분기 영구 여부 별도 확정 | 캐릭터/분기 UI 전 |
| D08 | 10~29 도적 무기별 힘·재주 | 무기 적용 규칙 표시, 30분기 별도 무료 배분 | 성장 구현 전 |
| D09 | 기존 방어구 생명력+장비 체력 중복 | 이전 직접 생명력값 재산정 | 장비 수치 적용 전 |
| D10 | 재련 강화 유지 비용·70% 계승 잔액 | 이중 환급·순환 계승·저등급 우회 비용 검증 | 재련/계승 구현 전 |
| D11 | 보상 참여 자격·초반 사망 | 낮은 피해량 자동 탈락 금지, 활동 및 관전 처리 구체화 | 보상 구현 전 |
| D12 | 직접거래·바닐라 가방 복제 | DB 소유권 원본, 우회 경로 제한 | 물품 구현 전 |
| D13 | 스킬 계수·기력·쿨다운·고유 자원 | 기술별 데이터표를 전투 검증과 함께 작성 | 스킬 구현 전 |
| D14 | 필드 사망·귀환과 위치 복원 | 공략 데스카운트를 필드에 임의 확장하지 않음 | 필드 사망 구현 전 |
| D15 | 1~20 시험에서 30분기 무기 체험 | 직업 공통 스킬의 무기 호환표와 보조 조작 정의 | 무기 구현 전 |
| D16 | 호스팅·동접·복구 목표·정확 의존성 버전 | 예산/목표 설정 및 A단계 실측 | 외부 시험 공개 전 |

## 5. 개발 중 변경 관리

- 게임 규칙이나 수치를 변경하면 관련 문서를 함께 수정한다.
- 콘텐츠 ID는 이름 수정으로 바꾸지 않음. 배포 후 변경에는 데이터 마이그레이션 필요.
- 익스플로잇·물품 손실은 출시 차단 결함, 수치 불균형과 분리해 우선 수정.
- 전투 재미는 단위 시험만으로 합격 처리하지 않음. 실제 플레이 관찰 필요.
- 이후 30분기 → 40~50레이드 → 60마스터 → 전체 생활·경제 순으로 별도 계획을 작성.
